Objective: add a read-only script that measures the worker prompt zc would build for given task files, without dispatching a worker. No change to any file under src/.

Decisions (final):
- New file `scripts/measure.mjs` (ESM, Node >= 22 built-ins only, no dependencies). Usage:
  `node scripts/measure.mjs prompt [--project <dir>] [--packs <a,b>] <task.md>...`
  - `--project` defaults to `process.cwd()`. `--packs` (comma list) overrides `config.ecc.rulePacks` for this measurement only (in memory; never writes config).
  - For each task file: load config with `loadConfig(root)` from src/config.mjs and the task the same way `zc dispatch --dry-run` does in src/cli.mjs (read cli.mjs to copy that exact path), then call `dispatch({ root, task, config, dryRun: true })` from src/dispatch.mjs, which returns `{ prompt }` with no side effects.
  - Section sizes: `eccRules` = `loadEccRules(config)`, `eccAssets` = `loadEccAssets(config, task)` from src/prompt.mjs.
  - Print one JSON object to stdout (2-space indent):
    `{ kind: "prompt-size", generatedAt: <ISO>, commit: <git rev-parse HEAD or null>, node: process.version, rulePacks: [...], maxChars: config.ecc.maxChars, tasks: [ { file, promptBytes, promptChars, eccRulesChars, eccAssetsChars, rulesTruncated } ] }`
    `promptBytes` = `Buffer.byteLength(prompt, 'utf8')`; `rulesTruncated` = whether eccRules contains `[... ECC rules truncated`.
  - Export `measurePrompts({ root, files, packs })` returning that object so tests call it directly; run the CLI only when the file is the entry point (`import.meta.url === pathToFileURL(process.argv[1]).href`).
  - Errors (missing task file, bad args): message to stderr, exit code 1. Unknown subcommand: usage to stderr, exit 1.
- Keep it under ~120 lines. Read-only: never writes files, never touches runs or git state.

Read first: src/cli.mjs (dry-run path), src/dispatch.mjs (`dispatch`, `taskPrompt`), src/prompt.mjs, test/helpers.mjs (`makeRepo`), test/units.test.mjs for test style.

Do not: edit src/, change result.json, add dependencies, dispatch workers.

Done when: `test/measure.test.mjs` (node:test) covers: a temp repo from `makeRepo` with a task file gives promptBytes > 0 and promptBytes === Buffer.byteLength of the dry-run prompt; `packs: []` gives eccRulesChars 0; a missing task file throws. Tests must not need installed ECC packs (use `packs: []` or the config `makeRepo` writes).

If blocked: report the contradiction with file:line.
