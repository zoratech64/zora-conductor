Objective: workers get only worker-relevant ECC rule files, the rules budget drops whole files instead of slicing text, and each run records which rule files were included, excluded and omitted.

Decisions (final, do not reopen):
1. src/prompt.mjs: replace the `CLAUDE_ONLY` set with `WORKER_EXCLUDED_RULES = new Set(['hooks.md', 'agents.md', 'development-workflow.md', 'performance.md', 'code-review.md', 'git-workflow.md'])`, with a one-line comment: manager/Claude-Code workflow rules (planner agents, GitHub search, commits, model choice) that contradict or do not apply to a worker. Exclusion applies to every pack by file name (as today). security.md, testing.md, coding-style.md, patterns.md and all language-pack files stay.
2. New exported `selectEccRules(config)` returning `{ text, included, excluded, omitted }`:
   - Walk packs in `config.ecc.rulePacks` order, files sorted by name (as today; same pack-not-found error). Label = `<pack>/<name>`. Excluded files go to `excluded` (labels) and are not read.
   - Section text = `### <label>\n<body>` (as today). Budget = `config.ecc.maxChars`, cost per section = `text.length + 2`. Add sections in order while they fit; at the first section that does not fit, stop: it and all later sections go to `omitted`. Never slice a section.
   - If the very first section does not fit, throw `Error('ECC rule <label> is <n> characters, over ecc.maxChars (<max>); raise ecc.maxChars or remove the pack')`.
   - `text` = included sections joined with `\n\n`; if `omitted` is non-empty append `\n\n[ECC rules omitted - over ecc.maxChars (<max>): <labels comma-separated>]`. No rule packs: `{ text: '', included: [], excluded: [], omitted: [] }`.
   - This mirrors `formatAssets` in src/ecc.mjs (whole-section, stop at first that does not fit, throw if first is too big). Do not change src/ecc.mjs.
3. Keep `loadEccRules(config)` exported with the same signature, returning `selectEccRules(config).text` (src/cli.mjs doctor and existing tests call it; do not edit cli.mjs).
4. src/dispatch.mjs `taskPrompt`: call `selectEccRules(config)` once, pass `.text` as `eccRules` to `buildPrompt`, and return `eccRules: { included, excluded, omitted }` alongside `allowed/verify/prompt`. In `dispatch`, after the run's `result` object exists, set `result.eccRules` to that object (new optional field; no other result field changes). Dry-run return stays as is.
5. docs/ARCHITECTURE.md line ~42: replace "capped at `ecc.maxChars`" with a short statement: manager-only rule files are left out; whole files are dropped (never cut) past `ecc.maxChars`, and `result.json` records `eccRules` included/excluded/omitted.
