Objective: close review 3 finding 1 (MEDIUM) on commit 2ef28f0. The two tests added by T-023 also pass on the pre-fix source (`HEAD~1`), so nothing fails if `finish()` goes back to taking a fresh snapshot. Add a test that fails on the pre-fix source and passes on HEAD.

Required behavior to test: when the working tree changes after zc takes its post-verify snapshot (`postState`, src/dispatch.mjs:389) and before `finish()` writes `result.json`, the OK result's `workerState` still equals the checked snapshot, so `acceptRun` throws /ambiguous ownership/ with nothing staged.

Seam: the test must make the tree change between those two points without sleeping or racing. The manager chooses and verifies the seam before dispatch and writes it into this file under "Seam". Candidates: a `git` wrapper first on PATH that writes the file on a chosen invocation after verify finishes; or a test-only wrapper around `dirtyState`. Production code (src/) must not change. If no seam exists without editing src/, stop and report.

- The test fails when run against the pre-fix source. Proof: `git archive HEAD~1 | tar -x -C <empty dir>`, copy the new test file in, run `node --test test/safety.test.mjs`; the new test, and only it, fails. The worker cannot run commands, so the manager runs this proof.

Seam (verified by the manager: passes on HEAD, fails on HEAD~1 and only there):
`finish()` is called right after `postState = G.dirtyState(root)` with no git call in between, so the only moment to change the tree is inside that snapshot. The last git call of `dirtyState` is `git ls-files -s`. A `git` wrapper first on PATH runs the real git, then, once and only after the verify command has run (a marker file written by the verify command), writes `src/a.txt`. On HEAD the recorded workerState predates that write, so accept throws. On the pre-fix source `finish()` re-snapshots and absorbs the write, so accept does not throw.

Edits to test/safety.test.mjs:
1. Add `import { spawnSync } from 'node:child_process';` and change `import { join } from 'node:path';` to `import { delimiter, join } from 'node:path';`. No other import changes.
2. Append exactly this test at the end of the file (no changes to any existing test):

```js
test('post-verify: a write after the post-verify snapshot cannot be absorbed into result.workerState', async (t) => {
  if (process.platform === 'win32') return t.skip('POSIX git wrapper');
  makeHome();
  const { dir, config } = makeRepo();
  addFake('g1', { mode: 'ok', write: { 'src/a.txt': 'a' } });
  const bin = mkdtempSync(join(tmpdir(), 'zc-gitwrap-'));
  const marker = join(bin, 'verify-ran');
  const done = join(bin, 'late-written');
  const realGit = spawnSync('which', ['git'], { encoding: 'utf8' }).stdout.trim();
  // After verify has run, the first `git ls-files -s` (the last read of the post-verify snapshot) is
  // followed by one write to the accepted file, so the tree changes exactly after that snapshot.
  const wrapper = [
    `#!${process.execPath}`,
    "const fs = require('fs');",
    "const r = require('child_process').spawnSync(process.env.ZC_T_REAL_GIT, process.argv.slice(2), { stdio: 'inherit' });",
    "const a = process.argv;",
    "if (a.includes('ls-files') && a.includes('-s') && fs.existsSync(process.env.ZC_T_MARKER) && !fs.existsSync(process.env.ZC_T_DONE)) {",
    "  fs.writeFileSync(process.env.ZC_T_DONE, '1');",
    "  fs.writeFileSync(process.env.ZC_T_LATE, 'late');",
    '}',
    'process.exit(r.status ?? 1);',
    ''
  ].join('\n');
  writeFileSync(join(bin, 'git'), wrapper);
  chmodSync(join(bin, 'git'), 0o755);
  const savedPath = process.env.PATH;
  Object.assign(process.env, {
    PATH: `${bin}${delimiter}${process.env.PATH}`,
    ZC_T_REAL_GIT: realGit, ZC_T_MARKER: marker, ZC_T_DONE: done, ZC_T_LATE: join(dir, 'src/a.txt')
  });
  try {
    const tk = scoped();
    tk.meta.verify = [[process.execPath, '-e', `require('fs').writeFileSync(${JSON.stringify(marker)}, '1')`]];
    const r = await dispatch({ root: dir, task: tk, config });
    assert.equal(r.status, 'OK');
    assert.ok(existsSync(done), 'the late write must have happened');
    assert.equal(readFileSync(join(dir, 'src/a.txt'), 'utf8'), 'late');
    assert.throws(
      () => acceptRun({ root: dir, runId: r.runId, config }),
      (err) => { assert.match(err.message, /ambiguous ownership/); return true; }
    );
    assert.equal(git(dir, 'diff', '--cached', '--name-only').trim(), '');
  } finally {
    process.env.PATH = savedPath;
    for (const k of ['ZC_T_REAL_GIT', 'ZC_T_MARKER', 'ZC_T_DONE', 'ZC_T_LATE']) delete process.env[k];
  }
});
```
