Objective: `node scripts/measure.mjs prompt` must report `rulesTruncated: true` when `selectEccRules` omits any ECC rule file for `ecc.maxChars`, and `false` otherwise. Nothing else in the measurement output changes.

Root cause (verified 2026-11-15 from source and a scratch probe):
- scripts/measure.mjs:115 sets `rulesTruncated: eccRules.includes('[... ECC rules truncated')`.
- That marker was written by the old character-cut `loadEccRules`, removed in commit 9b23489 (T-004): `${text.slice(0, max)}\n[... ECC rules truncated at ${max} characters]`.
- Since T-004, src/prompt.mjs:128-132 (`selectEccRules`) drops whole files and writes `[ECC rules omitted - over ecc.maxChars (${max}): <labels>]`, and returns the dropped labels as `omitted` (src/prompt.mjs:134). `loadEccRules` (src/prompt.mjs:140-142) returns only `.text`.
- The old marker can no longer appear, so `rulesTruncated` is always `false`.
- Probe: fakeEcc plus `rules/common/x-big.md` (1200 chars), packs `['common']`, `ecc.maxChars` 1000. `selectEccRules` gives `omitted: ['common/x-big.md']` and the text holds `[ECC rules omitted - over ecc.maxChars (1000): common/x-big.md]`, but `measurePrompts` returns `rulesTruncated: false`.
- Existing tests miss it: test/measure.test.mjs:36 and :52 assert only `false`, in cases with no omission.

Decisions (final):
1. scripts/measure.mjs: derive the flag from the structured `omitted` list, not from marker text.
   - Line 9: import `selectEccRules` in place of `loadEccRules` from `../src/prompt.mjs`. Keep `loadEccAssets`.
   - Line 106: `const { text: eccRules, omitted } = selectEccRules(config);`
   - Line 115: `rulesTruncated: omitted.length > 0`
   - `eccRulesChars` stays `eccRules.length`. It is the same string `loadEccRules` returned, so its value does not change.
2. Output compatibility: keep the field name `rulesTruncated` and its boolean type. Keep every other key, its order and its value in the `prompt-size` object and its `tasks` entries. Do not change the `runs` or `compare` subcommands; neither reads `rulesTruncated`.
3. CHANGELOG.md: under `## [Unreleased]`, after the existing `### Changed` block, add:
   ```
   ### Fixed

   - `scripts/measure.mjs prompt` reports `rulesTruncated: true` again when ECC rule files are left out past `ecc.maxChars`. Since whole-file rule selection it looked for a marker that is no longer written, so it was always `false`.
   ```
