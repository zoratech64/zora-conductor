Objective: close review 3 finding 3 (LOW) on commit 2ef28f0. The manager's probe used delays of 20 ms and up, so every late write landed after the check. It never reached the window the fix narrows and would have passed on the old code. Provide a repeatable probe with sub-20 ms delays that reports where each write landed.

Decisions (final):
1. Add scripts/probeLateWrite.mjs, a manual script that is not run by `npm test`. It uses the same temporary repos and fake worker as the tests (imports from test/helpers.mjs and src/dispatch.mjs), never touches the real repository, and takes optional arguments: a comma list of delays in ms (default `0,1,2,5,10,20,60,100,200,300,450,600`) and a repeat count (default 2).
2. For each delay and repeat: the worker writes `src/a.txt` as `a`; verify starts a detached `node` child that writes `EVIL` into `src/a.txt` after the delay and exits 0 at once; after the run, wait 900 ms, then call `acceptRun` and read the staged content.
3. Classify each row as `before-check` (`verifyChanged` lists `src/a.txt`), `after-check` (status OK, no `verifyChanged`, accept refused with "ambiguous ownership") or `FAIL` (EVIL ended up staged, or any other outcome). Print one line per row and a count per class.
4. Exit 1 if any row is `FAIL`, else 0. A run where no row is `before-check` is reported with the note `window not reached`; that is not a failure.
5. docs/audits/ZC-HARDENING-SPEC.md: after the ZCH-001 step 4 amendment of 2026-11-16 (independent review 2), append one sentence naming the script and its purpose: ` The manual probe \`scripts/probeLateWrite.mjs\` repeats the delayed-writer check with sub-20 ms delays; it guards the property, it does not prove the race is closed.` Change nothing else in the spec.

Acceptance criteria:
- `node scripts/probeLateWrite.mjs` exits 0 on HEAD and prints the per-class counts.
- With `0,1,2,5` as delays, the output is reported honestly whether or not any row is `before-check`.
- `npm test` and `npm run check` pass (the new script must pass the syntax check; add no dependency).
- `git diff --name-only` lists only the two allowed paths.

Do not: change src/, other scripts, tests, package.json, or any .zc/ file.
