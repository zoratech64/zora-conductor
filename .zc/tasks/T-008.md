Objective: extend scripts/measure.mjs with two read-only subcommands: `runs` (aggregate existing result.json files) and `compare` (fair before/after comparison of two `prompt-size` outputs). No src/ changes, no dependencies, never writes any file.

Decisions (final):
1. `node scripts/measure.mjs runs [--project <dir>] [--all-projects] [--split <ISO date>]`
   - Directories: default `runsDir(root)` (src/paths.mjs; root = --project or cwd). `--all-projects`: every `<stateRoot()>/projects/*/runs`. Missing dir = zero runs, not an error.
   - Exported pure-ish `reportRuns({ dirs, split })`: for each `<dir>/<run>/result.json`, read with readFileSync + JSON.parse in try/catch. Unreadable, malformed, or not a plain object with a string `runId` -> push `{ path, error }` to `unreadable` and skip. Never write or rename anything.
   - Groups: without split, one group `all`. With split: `before` (startedAt < split), `after` (startedAt >= split), `undated` (no parseable startedAt). Invalid split -> error.
   - Per group: `{ runs, statuses: {<status>: n}, repairRuns: <count with repairOf>, attempts: <total attempts>, metrics }`. `metrics` has these keys, each `{ n, missing, median, mean, min, max }` (n = count of finite numbers, missing = count of entries without a finite number, never treated as 0; stats null when n is 0; mean rounded to 1 decimal):
     per attempt (`result.attempts[]`): `promptBytes` (metrics.promptBytes), `turns` (metrics.turns), `toolsTotal` (metrics.tools.total), `toolsFailed` (metrics.tools.failed), `workerInputTokens` (metrics.usage.input_tokens), `workerOutputTokens` (metrics.usage.output_tokens), `workerTotalTokens` (metrics.usage.total_tokens), `attemptDurationMs` (durationMs); per run: `attemptsPerRun` (attempts.length, always present when attempts is an array), `verifyDurationMs` (result.verifyDurationMs).
   - Output: `{ kind: "run-report", generatedAt, dirs, split, unreadable, groups, notes }` with `notes` exactly: `["promptBytes is prompt size, not token usage.", "worker*Tokens are Gemini worker usage reported by agy; they say nothing about Claude (manager) token use.", "missing counts entries without that field; they are never counted as zero."]`.
2. `node scripts/measure.mjs compare <pre.json> <post.json>`
   - Exported `comparePromptSizes(pre, post)`. Both must have `kind: "prompt-size"`, else throw. If `rulePacks` (same order) or `maxChars` differ, return `{ kind: "prompt-compare", comparable: false, reason: <which differs>, tasks: [] }`.
   - Otherwise pair tasks by `file`; unpaired files listed in `unpaired`. Per pair: `{ file, preBytes, postBytes, deltaBytes, deltaPct (1 decimal), preRulesChars, postRulesChars }`. Output `{ kind: "prompt-compare", comparable: true, pre: {commit, generatedAt}, post: {commit, generatedAt}, tasks, unpaired }`.
3. Keep the existing `prompt` subcommand and `measurePrompts` unchanged. Update the usage string to list all three subcommands. Same error handling: stderr + exit 1.
4. docs/ARCHITECTURE.md: add a short "## Measuring efficiency" section at the end (5-8 lines): the three commands, that they are read-only and dispatch no worker, that missing fields are reported as missing, and that worker metrics are not Claude token use.
