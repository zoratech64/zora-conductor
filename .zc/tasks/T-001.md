Objective: record per-attempt execution metrics in result.json using data zc already parses. Additive only: no existing field, status, exit code or behavior changes. Do not touch src/agy.mjs, fixtures/ or any safety code (scope, snapshot, rollback, locks).

Decisions (final, do not reopen):
- New pure module `src/metrics.mjs` exporting `attemptMetrics(parsed, prompt)`. `parsed` is the object returned by `parseAgyOutput` in src/agy.mjs (fields used: `status`, `turns`, `usage`, `tools` = [{name, failed}]). Returns:
  `{ promptBytes, turns, usage, tools: { total, failed, byName }, fileOps: { read, edit, write } }`
  - `promptBytes`: `Buffer.byteLength(prompt, 'utf8')`.
  - `turns`: `parsed.turns` if `parsed.status` is non-empty (a result event was seen), else `null`.
  - `usage`: `parsed.usage` as given (plain object copy), else `null`. Do not rename or derive token fields; Gemini's keys (input_tokens, output_tokens, thinking_tokens, cache_read_tokens, total_tokens) pass through untouched.
  - `tools.total` = `parsed.tools.length`; `tools.failed` = count with `failed === true`; `tools.byName` = `{ [name]: count }`.
  - `fileOps` counts by exact tool name: `read_file` -> read; `edit_file` -> edit; `write_file` and `write_to_file` -> write. Other tools appear only in `byName`. No guessing from other names.
  - Empty/missing `parsed.tools` gives zeros, never throws.
- In `src/dispatch.mjs`, right after `attempt.durationMs = Date.now() - started;` set `attempt.metrics = attemptMetrics(r.parsed, prompt);` so failed, timed-out and successful attempts all get it. Keep `attempt.durationMs` exactly as it is. Import from './metrics.mjs'.
- Verification timing: in `src/verify.mjs` add `durationMs` (integer ms, `Date.now()` difference around each `run(...)`) to each result object in the array; keep every existing field (`cmd`, `ok`, `code`, `timedOut`, `tail`). In dispatch.mjs around the existing `runVerify` call, set `result.verifyDurationMs` = total wall ms of that call. Do not run verification any extra time and do not change when it runs.
- Not measured, do NOT add or invent: Claude usage, AGY startup time, prompt-build time, per-file read paths, search counts, thinking-step counts.
- Older result.json files lack these fields; nothing may require them. `formatResult` stays unchanged.
