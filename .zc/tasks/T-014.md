Objective: under a tight `ecc.maxChars`, `selectEccRules` must keep every `security.md` and `testing.md` rule file, dropping other rule files first. If those files alone do not fit, it throws instead of omitting them. When everything fits, the output stays byte-identical to today.

Root cause (verified): src/prompt.mjs:75 lists each pack's files alphabetically, and the loop at src/prompt.mjs:92-98 keeps a prefix and stops at the first file that does not fit. `security.md` and `testing.md` sort last in `common` and `dart`, so they are the first files omitted. Bundled packs fit today (common+typescript 12456 chars, common+dart about 28k, against a 40000 default), so the defect shows only with an installed ECC or a lowered `maxChars`.

Decisions (final):
1. src/prompt.mjs: add an export directly below `WORKER_EXCLUDED_RULES`:
   `/** Worker rule files that are never dropped for budget: if they do not fit, selection fails instead. */`
   `export const WORKER_REQUIRED_RULES = new Set(['security.md', 'testing.md']);`
   The match is on the file name, in any pack, ignoring case. Do not change `WORKER_EXCLUDED_RULES`.
2. In `selectEccRules`, give each candidate a `required` flag: `WORKER_REQUIRED_RULES.has(name.toLowerCase())`, so `Security.md` or `TESTING.md` also count. Labels and output keep the file's real name. Leave the candidate collection loop otherwise unchanged; candidates stay in pack order, then file name.
3. Replace the selection loop (src/prompt.mjs:86-104) with this logic:
   - Selection order: all required candidates in candidate order, then all others in candidate order.
   - Walk that order and keep a running `used` with the same cost as today, `text.length + 2`.
   - If a candidate fits (`used + cost <= max`), choose it.
   - If it does not fit and nothing has been chosen yet, throw the existing error unchanged: `ECC rule ${label} is ${text.length} characters, over ecc.maxChars (${max}); raise ecc.maxChars or remove the pack`.
   - If it does not fit and it is required, throw `ECC rule ${label} is required for workers (security/testing) but does not fit in ecc.maxChars (${max}) after ${used} characters of other required rules; raise ecc.maxChars or remove a pack`.
   - If it does not fit and it is not required, stop. Every remaining candidate is omitted; keep "stop at the first non-fit" and do not skip ahead to smaller files.
   - Build `included`, the included section texts and `omitted` by filtering candidates in ORIGINAL candidate order, not in selection order. When everything fits, `text` and `included` are therefore identical to today.
   - Keep the omission marker text and how it is built (src/prompt.mjs:105-110) exactly as it is.
   - Edge rules (each one has a test below):
     - No candidates at all (every file excluded, or the pack has no .md files): return `{ text: '', included: [], excluded, omitted: [] }` without throwing, as today.
     - No required candidates: behavior is exactly today's prefix selection.
     - The first required file alone exceeds the budget, even when a non-required file sorts before it and would fit: nothing has been chosen yet, so throw the existing "is N characters, over ecc.maxChars" message naming that required file. Never fall back to including the non-required file.
4. Return shape stays `{ text, included, excluded, omitted }`. No change to `loadEccRules`, `buildPrompt`, dispatch, `result.eccRules`, config validation or `maxChars` limits.
5. The doc comment on `selectEccRules` gains one sentence: security.md and testing.md are selected first and never omitted; if they do not fit, it throws.
6. docs/ARCHITECTURE.md line 42: after "whole files are dropped (never cut) past `ecc.maxChars`" add "; `security.md` and `testing.md` are kept first and never dropped: if they do not fit, dispatch stops with an error".
7. CHANGELOG.md, under `## [Unreleased]`, add:
   ```
   ### Changed

   - Worker prompts always keep the ECC `security.md` and `testing.md` rule files: past `ecc.maxChars`, other rule files are dropped first, and if those two files alone do not fit, `zc dispatch` (and `zc doctor`) report an error instead of leaving them out.
   ```
